# educational-video-chain · Skill para Claude

Skill gratuita para crear **vídeos educativos verticales (Shorts, Reels, TikTok; máximo 70 s)** que explican cómo se construye o funciona algo mediante una cadena de **problemas reales y soluciones**: de la versión más ingenua hasta el sistema que funciona.

Incluye todo el proceso: idea, investigación con fuentes, mapa narrativo, guion en español, storyboard técnicamente preciso y, opcionalmente, producción con IA (Higgsfield MCP) con presupuesto en créditos.

## Descarga

👉 **[Descargar el ZIP](../../releases/latest)** (sección *Releases*, archivo `educational-video-chain.zip`).

## Instalación

**Claude Code (escritorio o terminal)**

1. Descomprime el ZIP.
2. Copia la carpeta `educational-video-chain/` en `~/.claude/skills/` (en Windows: `%USERPROFILE%\.claude\skills\`).
3. Abre una sesión nueva y pide, por ejemplo: «Quiero un short sobre cómo funciona un ascensor».

**Claude (claude.ai o app de escritorio)**

1. Activa las skills en *Configuración → Capacidades*.
2. Sube el archivo ZIP en la sección de skills.

## Requisitos

- **Idea, investigación, guion y storyboard:** no necesitan nada más.
- **Producción (imágenes, vídeo y voz con IA):** necesita el conector **Higgsfield MCP** y gasta **créditos de tu cuenta de Higgsfield**. La skill presupuesta cada fase y no gasta nada sin tu autorización.

Más detalles en [educational-video-chain/README.md](educational-video-chain/README.md).
