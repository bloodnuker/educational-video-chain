# Rúbrica de progresión causal

Úsala en la Fase 5, sobre el mapa narrativo, **antes** de escribir el guion. Vuelve a usarla si cambias el mapa.

## Cómo puntuar

Cada criterio se puntúa de 0 a 2:

- **0**: no se cumple.
- **1**: se cumple con debilidades concretas (nómbralas).
- **2**: se cumple con claridad.

Total máximo: 24. Umbral para pasar al guion: **≥ 19** y **ningún criterio bloqueante (B) en 0**. Un bloqueante en 1 obliga a dejar por escrito la corrección o la limitación.

Entrega la evaluación como tabla: criterio · puntuación · evidencia (qué etapa lo demuestra o lo rompe) · corrección aplicada.

## Criterios

| # | Criterio | B | Qué comprobar | Señal de 0 |
|---|---|---|---|---|
| 1 | Premisa inmediata | | ¿Se entiende en una frase y se visualiza en un segundo? | Hace falta contexto técnico para entender el punto de partida |
| 2 | Objetivo final observable | ✔ | ¿Hay un criterio de éxito que se pueda *ver* al final? | El vídeo "acaba" sin que el sistema cumpla nada concreto |
| 3 | Problemas reales | ✔ | ¿Cada problema está documentado o es consecuencia física directa y verificable? | Un fallo inventado o exagerado para crear tensión |
| 4 | Causalidad honesta | ✔ | En las etapas tipo A, ¿la solución anterior causa de verdad el reto? En las tipo B, ¿se presenta como nueva condición y no como consecuencia? | "Por eso…" donde no hay relación causal |
| 5 | Soluciones tangibles | ✔ | ¿Cada solución es un objeto, pieza, modificación o procedimiento que se puede mostrar? | "Se mejora", "se optimiza", "se usa tecnología" |
| 6 | Acumulación | | ¿El sistema conserva lo anterior y crece? ¿Las soluciones siguen visibles en etapas posteriores? | Cada etapa empieza de cero o se olvida lo construido |
| 7 | Escalada natural | | ¿La complejidad sube sin saltos de comprensión? ¿Cada concepto nuevo se apoya en uno previo? | Un concepto avanzado aparece antes que su base |
| 8 | Variedad de retos | | ¿Mezcla tipo A y B? ¿Varían las fuentes de dificultad (física, tiempo, uso, entorno, humanos)? | Todos los retos son del mismo tipo o se resuelven igual |
| 9 | No es una lista | ✔ | Prueba de reordenación: si intercambias dos etapas cualesquiera, ¿se rompe la lógica? | Se pueden reordenar libremente |
| 10 | Visualizable | | ¿Cada etapa tiene una prueba visual concreta que explique el mecanismo sin narración? | La prueba visual es un plano genérico |
| 11 | Aprendizaje por etapa | | ¿Cada etapa deja un concepto claro y no redundante? | Dos etapas enseñan lo mismo |
| 12 | Recompensa final | | ¿El cierre aporta algo nuevo (dato, consecuencia inesperada, detalle humano) y verificado? | Resumen, moraleja o dato sin fuente |

## Pruebas rápidas

- **Prueba de reordenación** (criterio 9): toma dos etapas no adyacentes e intercámbialas. Si la historia sigue funcionando igual, al menos una de ellas no depende de lo anterior. En etapas tipo B esto es aceptable solo si la condición nueva tiene su propio orden natural (día → noche → invierno; superficie → inmersión → profundidad).
- **Prueba del "¿y entonces?"**: después de cada solución, pregunta "¿y entonces qué falla o qué cambia?". Si la respuesta es "nada, pero además…", es una característica añadida, no una etapa.
- **Prueba de la fuente**: señala cada problema y pregunta "¿dónde está documentado?". Sin respuesta, la etapa se marca como pendiente o se elimina.
- **Prueba del espectador sin sonido**: lee solo la columna "Prueba visual". ¿Se entiende la evolución?

## Correcciones típicas

| Fallo | Corrección |
|---|---|
| Causalidad forzada | Reetiqueta la etapa como tipo B y preséntala como cambio de condición ("Ahora queremos bajar más") |
| Lista de componentes | Busca el problema que obligó a inventar cada componente y ordena por ese problema, no por el componente |
| Todo catástrofes externas | Introduce al menos una etapa en la que la propia solución genere el reto |
| Solución abstracta | Nombra la pieza, dónde está, qué hace físicamente |
| Demasiadas etapas para la duración | Fusiona etapas con el mismo aprendizaje; elimina la de menor recompensa visual |
| Tema con pocos problemas reales | Cambia el punto de partida (más ingenuo), la escala, o el ángulo (histórico: cómo se resolvió por primera vez) |
